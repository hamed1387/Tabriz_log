# Tabriz Places

دفترچهٔ کافه‌ها و مکان‌هایی که در تبریز تجربه کرده‌ایم.

این پروژه یک **سایت استاتیک** است: HTML، CSS، JavaScript و یک فایل CSV. هیچ بک‌اند، دیتابیس یا سرور اختصاصی لازم ندارد و روی **GitHub Pages** میزبانی می‌شود.

## ساختار پروژه

```text
Tabriz_log/
├── index.html              # تنها صفحهٔ سایت
├── assets/
│   ├── css/
│   │   └── style.css       # استایل‌ها
│   ├── js/
│   │   └── script.js       # خواندن CSV، ساخت کارت‌ها، انیمیشن‌ها
│   └── img/
│       └── favicon.svg     # آیکون سایت
├── data/
│   └── places.csv          # دادهٔ مکان‌ها
├── tools/
│   └── start.bat           # اجرای سرور محلی برای پیش‌نمایش (ویندوز)
├── .gitignore
├── .nojekyll               # جلوگیری از پردازش Jekyll روی GitHub Pages
├── LICENSE
└── README.md
```

فقط `index.html` در ریشه است تا GitHub Pages بدون تنظیم اضافه آن را به‌عنوان صفحهٔ اصلی بشناسد. بقیهٔ فایل‌ها در پوشه‌های موضوعی قرار دارند.

## مرتب‌سازی

بالای فهرست یک منوی «مرتب‌سازی» وجود دارد:

| گزینه | نتیجه |
| --- | --- |
| بیشترین امتیاز | از بالا به پایین (پیش‌فرض) |
| کمترین امتیاز | از پایین به بالا |
| ترتیب فایل | همان ترتیب ردیف‌های CSV |

- در امتیازهای مساوی، ترتیب اصلی CSV حفظ می‌شود.
- تغییر مرتب‌سازی فوراً اعمال می‌شود و فایل CSV دست‌نخورده می‌ماند.
- تعداد مکان‌ها کنار منو نمایش داده می‌شود.

## انتشار روی GitHub Pages

1. مخزن را روی GitHub بسازید و فایل‌ها را در شاخهٔ `main` قرار دهید.
2. در مخزن به **Settings → Pages** بروید.
3. در بخش **Build and deployment**، گزینهٔ **Deploy from a branch** را انتخاب کنید.
4. شاخه را `main` و پوشه را `/ (root)` بگذارید و **Save** را بزنید.
5. سایت پس از حدود یک دقیقه در این آدرس در دسترس است:

   - مخزن عادی: `https://<username>.github.io/<repo>/`
   - مخزن `<username>.github.io`: `https://<username>.github.io/`

هر `push` روی شاخهٔ `main` سایت را به‌طور خودکار به‌روز می‌کند.

نکته‌ها:

- همهٔ مسیرها **نسبی** هستند، پس سایت هم در ریشه و هم در زیرمسیر مخزن کار می‌کند.
- نام فایل‌ها روی GitHub Pages به بزرگی و کوچکی حروف حساس است؛ مثلاً `data/places.csv` را دقیقاً با همین نام نگه دارید.
- GitHub Pages فایل‌ها را چند دقیقه کش می‌کند. کد با `cache: "no-store"` فایل CSV را می‌خواند، اما اگر باز هم تغییرات را ندیدید، چند دقیقه صبر کنید یا صفحه را با `Ctrl+F5` نو کنید.

## پیش‌نمایش محلی

برای دیدن سایت روی کامپیوتر باید آن را با یک سرور محلی باز کنید؛ چون `fetch` در مرورگر روی آدرس `file://` اجازهٔ خواندن `data/places.csv` را نمی‌دهد (باز کردن مستقیم `index.html` کار نمی‌کند).

- **ویندوز:** روی `tools\start.bat` دوبار کلیک کنید، سپس <http://localhost:8000> را باز کنید.
- **با پایتون:** از ریشهٔ پروژه `py -m http.server 8000`
- **با Node.js:** از ریشهٔ پروژه `npx serve .`

## افزودن یا ویرایش مکان

یک ردیف جدید به `data/places.csv` اضافه کنید:

```csv
name,icon,score,city,description
کافه نمونه,☕,8.5,تبریز,"یک توضیح کوتاه"
```

| ستون | توضیح |
| --- | --- |
| `name` | نام مکان (الزامی) |
| `icon` | ایموجی کنار نام؛ خالی بماند، ☕ استفاده می‌شود |
| `score` | امتیاز از ۰ تا ۱۰ (الزامی) |
| `city` | شهر |
| `description` | توضیح کوتاه |

نکته‌ها:

- فایل را با کدگذاری **UTF-8** ذخیره کنید (نسخهٔ فعلی برای نمایش درست در Excel با BOM ذخیره شده است).
- اگر متن یک ستون ویرگول انگلیسی (`,`) دارد، آن را داخل `"..."` بگذارید.
- ارقام فارسی و ویرگول اعشاری فارسی (٫) هم پذیرفته می‌شوند.
- ردیف‌های بدون `name` یا با `score` نامعتبر نادیده گرفته می‌شوند.
- ترتیب کارت‌ها همان ترتیب ردیف‌ها در CSV است.
